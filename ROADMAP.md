# Smart Wardrobe ERP Development Roadmap

## Phase 1 - Completed in this package
- One wardrobe (W01) and nine visible compartments, exact current counts by compartment.
- Clothing catalog with photo, category, name, color, size, notes and manual tag ID.
- Search and filter, movement history, exportable complete backup, owner password option.
- Responsive desktop and iPhone web interface, SQLite storage.

## Phase 2 - Next planned scope (not built yet)
- Customize the physical cabinet plan: number of compartments, widths/heights, drag/drop placement, shelves, drawers and hanging spaces.
- QR code / barcode registration and phone scanning, allowing quick garment check-in before RFID hardware exists.
- Clothing detail screens, tags/labels, sorting and easier bulk entry.
- Improve account roles, security, and mobile-first flows before any public deployment.

## Phase 3 - Hardware research and prototype (not built yet)
- Compare RFID / NFC / UHF RFID suitability with garment-mounted clip-on tags.
- Test real garments, read range, accuracy, adjacent-compartment detection and tag washability.
- Select hardware and build reader integration only after controlled pilot measurements.

## Phase 4 - Automated inventory (not built yet)
- Wardrobe sensor events matched to clothing records.
- Exception handling for missing/misread tags and manual audit reconciliation.
- Personalized clothing insights and reminders.

This is a roadmap, not a claim that hardware integrations or later features already work.
